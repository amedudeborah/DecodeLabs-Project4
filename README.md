# E-Commerce Sales Dashboard Using Power BI

## Overview

This project involves the development of an interactive Power BI dashboard to analyze e-commerce sales data. The dashboard provides insights into revenue, product performance, payment methods, referral sources, and order statuses through visualizations and key performance indicators (KPIs).

## Objectives

* Monitor overall sales performance
* Analyze revenue trends
* Evaluate product performance
* Examine customer payment preferences
* Track order statuses and business metrics

## Tools Used

* Microsoft Power BI
* Power Query
* DAX (Data Analysis Expressions)
* Microsoft Excel

## Dashboard Features

* Revenue Analysis
* Product Performance Analysis
* Payment Method Analysis
* Referral Source Analysis
* Order Status Distribution
* Monthly Revenue Trends
* Interactive Filters and KPIs

## Files Included

* Power BI Dashboard (.pbix)
* Project Report.pdf
* Dashboard Screenshots

## Outcome

The dashboard transformed raw transactional data into meaningful visual insights, enabling effective monitoring of business performance and supporting data-driven decision-making.
